# タブンネ｜商談管理表 自動記入スキル　使い方マニュアル

## これは何をするスキル？

商談が終わったあと、**商談管理表のスプレッドシートを自分で埋める作業をAIに任せる**スキルです。

カレンダーの予定名を渡すだけで、AIが次の3つを自動で読みに行って、管理表の1行を仕上げます。

1. **Googleカレンダーの予定** … 相手の会社名・お名前・メール・電話・商談日
2. **「Gemini によるメモ」（議事録・文字起こし）** … 話した内容・課題・反応・次アクション・金額
3. **Web検索** … カレンダーに無い会社情報（HP・事業内容・創業年・住所・従業員数）

初めての会社なら新しい行を作り、2回目以降は同じ会社の行を見つけて追記します
（初回 → 提案 → クロージングと段階が進みます）。

---

## 大事なこと：4つの列には絶対に書き込みません

次の4列は**判断が入る列**なので、AIは空欄でも一切触りません。ご自身で入力してください。

| 列 | 項目 |
|---|---|
| **Q** | ステータス |
| **Z** | 申請予定コース |
| **AA** | 商材 |
| **AC** | ヨミ判断／失注理由 |

商談ごとに「この4つだけ入れてください」と報告に出ます。

また、**A列が自分以外の担当者になっている行には書き込みません。**

## 導入手順（初回だけ・5分）

### 1. スキルを置く

ダウンロードしたzipを解凍し、`tabunne` フォルダごと下の場所に入れます。

```
C:\Users\（自分のユーザー名）\.claude\skills\
```

こうなればOKです。

```
.claude\skills\tabunne\SKILL.md
.claude\skills\tabunne\README.md
.claude\skills\tabunne\processed.json
```

### 2. 自分用の設定を4か所書き換える

`SKILL.md` をメモ帳などで開き、`固定パラメータ` の中にある
`<<...>>` の部分を自分の値に書き換えて保存します。

| 書き換える場所 | 入れる値 | 調べ方 |
|---|---|---|
| `<<商談管理表のスプレッドシートID>>` | 管理表のURLの `/d/` と `/edit` の間の長い文字列 | 管理表を開いてURLを見る |
| `<<案件管理表タブのgid>>` | URLの `gid=` の後ろの数字 | 案件管理表タブを開いた状態のURL |
| `<<自分の会社メールアドレス>>` | 自分のGoogleカレンダーのアドレス | 業務用メールアドレス |
| `<<自分の担当者名>>` | 管理表のA列「担当」に入る表記 | 管理表の既存行と同じ書き方に合わせる |

> 管理表のURLは営業チームで共有しているものを使ってください。
> セキュリティのため、スキル本体にはURLを埋め込んでいません。

### 3. 連携を確認する

Claude側で次がつながっている必要があります。つながっていない場合はAIが「見当たりません」と教えてくれます。

- Googleカレンダー
- Googleドライブ
- Chrome操作（Claude in Chrome）

### 4. 動作確認

Claude Code に、過去の商談のカレンダー予定名をそのまま貼り付けてみてください。
書き込む前に必ず「この内容でよろしいですか？」と確認が出ます。
内容を見て問題なければ「OK」と返すと書き込まれます。

## 使い方

### ① 商談1件を記入する（いちばん普通の使い方）

カレンダーの予定名をそのまま貼り付けるだけです。

```
〇〇株式会社 〇〇さん: 【MTG/AI】ライトアップ〇〇
```

または、こう言うだけでも動きます。

- 「タブンネ呼んで」「タブンネ回して」
- 「管理表を埋めて」「商談管理表に入れて」
- 「この商談をスプシに転記して」

会社名だけ、日付だけでも探しに行きます。見つからなければ日付を聞かれます。

### ② 商談のあとに自動で回す（任意）

定期実行タスクを作ると、カレンダーを見に行って
「終わっていて、議事録が付いていて、まだ管理表に入っていない商談」だけを自動で記入します。

- 何もなければ「巡回完了・新規なし」の一言だけ返します（これが普通の状態です）
- 議事録がまだ生成されていない商談は「🟡 議事録待ち」として残し、次回また拾います
- 同じ商談を二重に書かないよう、台帳とシートの両方を毎回チェックします

自動実行の設定はご自身で行ってください（設定方法はチーム内で共有しているものに従ってください）。

## AIが埋める項目と、埋めない項目

**埋める（29列）**
担当／会社名／姓／名／役職／メール／電話／役員数／正社員数／アルバイト数／HP／事業内容／創業年／
住所（都道府県・市区町村）／紹介元代理店／初回・提案・クロ商談日／受注日／初期費用／月額費用／
契約期間／金額合計／商談メモ／失注理由／文字起こしURL（初回・提案・クロ）

**埋めない（4列・ご自身で）**
ステータス／申請予定コース／商材／ヨミ判断・失注理由

### わざと空欄にする場合があります

推測で埋めないルールです。次のような場合は空欄のまま残し、理由を報告します。

- HPに従業員数の記載がない
- 商談で出た人数が業務委託・フルコミッションで、正社員数と一致しない
- 金額が「ざっくり」「概算」どまりで、正式に提示・合意した金額ではない
  （この場合、金額は商談メモ側に事実として書き残します）
- 失注が明言されていない

## うまくいかないときは

| 症状 | 原因と対処 |
|---|---|
| 「初回設定が済んでいません」と言われる | `SKILL.md` の `<<...>>` が残っています。手順2をやり直してください |
| 「カレンダーの連携が見当たりません」 | Claude側のGoogle連携が切れています。連携し直してください |
| 「議事録待ち」と出て記入されない | Geminiのメモがまだ生成されていません。しばらく経ってからもう一度 |
| 「ヘッダーが違います」と出て止まった | 管理表の列が増減しています。勝手に書かずに止まる仕様です。共有してください |
| 途中で止まった | 集めた内容は必ずチャットに「そのまま貼れる形」で出ます。手で貼れば復旧できます |

**書き込みに失敗しても黙って終わることはありません。**
どこまで書けて、どこが書けなかったかを必ず報告します。

---

## やらないこと（安全のため）

- 承認なしの書き込み（自動実行を除く）
- ステータス・申請予定コース・商材・ヨミ判断の4列への書き込み
- 他の担当者の行への書き込み
- 顧客リスト（営業チーム全体の管理ブック）への書き込み
- カレンダーの予定の作成・変更・削除
- メールの送信・下書き作成、Slackへの投稿（タブンネの担当外です）
- 行・シート・ファイルの削除、共有設定の変更
- 数字・役職・人数・創業年を推測で書くこと
