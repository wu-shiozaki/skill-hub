# スキルセンター（GitHub Pages用）

社内スタッフにAI自動化スキルを配るための、1ページのサイトです。

```
index.html                     配布ページ本体
files/absol.zip                アブソル本体
files/absol-manual.md          アブソルのマニュアル
files/nendoll.zip              ネンドール本体
files/nendoll-manual.md        ネンドールのマニュアル
```

---

## 初回だけやること（10分）

1. GitHubでリポジトリを作る（例：`skill-hub`）
2. このフォルダの中身を、フォルダ構造のままアップロードする
3. リポジトリの Settings → Pages を開く
4. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
5. 数分待つと、次のURLで公開される

```
https://<アカウント名>.github.io/<リポジトリ名>/
```

**このURLは以後ずっと変わりません。** 社内にはこのURLだけを共有します。

---

## 更新するとき

| やりたいこと | やること |
|---|---|
| スキルの中身を直す | `files/◯◯.zip` を、同じファイル名で差し替える |
| マニュアルを直す | `files/◯◯-manual.md` を、同じファイル名で差し替える |
| スキルを追加する | `files/` にzipとマニュアルを置き、`index.html` にカードを1つ足す（**ラベルを必ず付ける**／下記） |
| 更新日を変える | `index.html` の「2件／更新 YYYY-MM-DD」を書き換える |

### スキルを追加するときのラベル

カードには「どちらのClaudeに入れるスキルか」のラベルを必ず付けます。
入れる場所が違うため、これが無いとスタッフが迷います。

| 種類 | 書くもの |
|---|---|
| Claudeチャット用（claude.ai／デスクトップアプリ） | `<span class="badge badge-chat">Claudeチャット用</span>` |
| Claude Code用 | `<span class="badge badge-code">Claude Code用</span>` |

書く場所は2か所です。

1. `<div class="card-top">` の中、`<span class="slug">` の次の行
2. `<dl class="meta">` の先頭の `使う場所` の行

既存のカードをコピーして作れば、両方まとめて付いてきます。
種類が違う場合だけ `badge-chat` と `badge-code` を入れ替えてください。

---

**ファイル名さえ変えなければ、URLは一切変わりません。**
スタッフに再共有する必要もありません。

反映には数分かかります。
すぐ確認したいときは、ブラウザのスーパーリロード（Ctrl+Shift+R / Cmd+Shift+R）を使ってください。

---

## 注意すること

- GitHub Pagesで公開したページは、**URLを知っていれば社外の人でも見られます**（無料プランの場合）。
  顧客名・スプレッドシートのID・Slackのチャンネル名・個人のメールアドレスなど、
  外に出て困るものはファイルに書かないでください。
  配布しているスキルは、そうした値をすべて「利用者設定」欄に外出しして、
  各自が自分の環境で入れる作りにしてあります。
- 社外に一切見せたくない場合は、GitHubの有料プラン（Pagesの非公開設定）にするか、
  Google Sitesなど社内認証のかかる場所に移す必要があります。
- リポジトリを公開（public）にするか非公開（private）にするかに関わらず、
  Pagesで公開したページ自体は上記のとおり見られる前提で運用してください。
