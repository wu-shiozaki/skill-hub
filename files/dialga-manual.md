# ディアルガ 使い方マニュアル

TimeRex（タイムレックス）の日程調整ページを、
条件を4つ言うだけで作って、予約URLを返してくれるスキルです。

**Claude Code用**のスキルです。Claudeのチャットではなく、Claude Codeに入れて使います。

---

## このマニュアルの使い方

**おすすめ：Claudeに丸投げする**
このファイルをそのままClaude Codeに渡して、次の一言を送ってください。

> このマニュアルの通りに、ディアルガのセットアップを進めて。

自分のTimeRex番号を調べるところから、テスト実行まで面倒を見ます。

**自分で進めたい人**：「1. 人がやること」だけ順にやれば終わります。

---

## 0. 準備するもの

| 必要なもの | 用途 | 無い場合 |
|---|---|---|
| Claude Code | スキルの実行 | 必須 |
| TimeRexのアカウント | 予約ページの作成先 | 必須。会社で契約しているものを使う |
| Claude in Chrome（ブラウザ拡張） | TimeRexの画面操作 | 必須。これが無いと何もできません |
| Chromeで TimeRex にログイン済みであること | 同上 | 必須。ログインはスキルではなく自分でやります |
| Googleカレンダー連携（TimeRex側） | 空き時間の判定 | 未連携だと全枠が空きとして出てしまいます |

---

## 1. 人がやること（所要5分）

### 1｜スキルを入れる

配布サイトから `dialga.zip` をダウンロードし、**解凍して**
`~/.claude/skills/` の下に置きます。こうなればOKです。

```
~/.claude/skills/dialga/SKILL.md
```

Windowsなら `C:\Users\<自分>\.claude\skills\dialga\SKILL.md` です。

### 2｜自分のTimeRex番号を調べる

Chromeで `https://timerex.net/` を開きます。
ログイン済みなら `https://timerex.net/user/12345` のようなURLに移動します。
この**末尾の数字**が自分の番号です。

### 3｜自分用に2か所だけ書き換える

`SKILL.md` の冒頭にある「利用者設定」を埋めます。

```yaml
timerex:
  user_id: "12345"      # ← 手順2で調べた番号
  host_name: "山田太郎"  # ← TimeRex上の自分の表示名
```

ここが空のままだと、スキルは動かずに番号を聞いてきます。

### 4｜Chromeでログインしておく

TimeRexにログインした状態のChromeを開いておきます。
**スキルはログイン操作をしません**（IDやパスワードを打つことは絶対にしません）。
ログイン画面が出たら、そこで止まって「ログインしてください」と言ってきます。

### 5｜テスト実行する

Claude Codeで、こう打ちます。

> ディアルガ呼んで。テスト用、30分、自分だけ。

出てきた予約URLを開いて、枠が想定どおりか確認してください。
確認できたら、TimeRexの管理画面からそのテスト用ページを消して構いません。

## 2. 毎日の使い方

条件を言うだけです。

> ディアルガ呼んで。「補助金活用のご相談」30分、自分だけ。

聞かれるのは**4つだけ**です。

| 聞かれること | 例 |
|---|---|
| タイトル | 補助金活用のご相談 |
| 所要時間 | 30分 |
| 参加メンバー | 自分だけ／〇〇さんと2人 |
| 参加方式 | 全員参加／ラウンドロビン（誰か1人が参加） |

最初から全部言っておけば、何も聞かれずにURLが返ってきます。

### 毎回自動で入る設定（聞かれません）

| 項目 | 設定 |
|---|---|
| 表示開始 | 18時間後から |
| 受付時間 | 平日 10:00〜19:00（土日・祝日は受付なし） |
| Web会議 | Google Meet を自動で発行 |
| 提示期間 | 直近14日間 |
| 表示間隔 | 自動 |
| 入力項目 | 会社名 → 名前 → メールアドレス → 電話番号 → コメント（**すべて必須**） |

「24時間後からにして」のように言えば、その場で変えられます。

### チームのルールが違う場合

受付時間や入力項目が自社と違うなら、`SKILL.md` の
`fixed_settings` と `guest_questions` を書き換えてください。
以後はその内容で作られます。

---

## 3. うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「TimeRex番号が未設定です」と言われる | 手順2〜3をやる |
| ログイン画面で止まる | Chromeで自分でログインしてから、もう一度呼ぶ |
| 画面が固まって進まない | TimeRexの管理画面は重いです。少し待てば復帰します。ダメなら作り直しになります |
| 設定画面で土日が「10:00-19:00」のまま | **TimeRexの表示バグです。設定自体は効いています。** スキルは公開ページで実際の枠を見て判定するので、そのまま任せてください |
| 土日に枠が出てしまっている | 「土日を外して」と言えば直します |

---

## 4. このスキルがやらないこと

安心して使えるように、次は絶対にしません。

1. **TimeRexへのログインをしません。** IDやパスワードは一切扱いません。
2. **既存の予約ページを消しません。** 作るのは新規1本だけです。
3. **他の人が作ったカレンダーを触りません。**
4. **チーム設定・会議室連携・アカウント設定を変えません。**
5. **発行したURLを顧客に送りません。** URLを返すところまでです。送るのは自分の手です。
6. **予約URLを推測で作りません。** TimeRexが発行した文字列をそのまま読み取って返します。
